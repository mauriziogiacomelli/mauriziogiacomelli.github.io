Le tecnologie che uso nei progetti, dalle applicazioni enterprise per banche, telecomunicazioni e pubblica
amministrazione fino a [Job Tracker](/lavori/job-tracker/), la mia applicazione su AWS.

## Linguaggi

**Java** (SE/J2EE, fino alla 21) · **TypeScript** · JavaScript · SQL e PL/SQL · HTML5 / CSS · XML / XSLT

## Backend Java

- **Spring**: Spring Boot (fino alla 4), Spring MVC, Spring Security, Spring Cloud, Spring AOP / AspectJ
- **Persistenza**: Hibernate / JPA, MyBatis, EJB 2/3
- **Architetture**: microservizi (Eureka), API REST e SOAP, messaggistica con RabbitMQ
- **Web tradizionale**: JSF (Facelets, PrimeFaces, RichFaces), Struts 1/2, Servlet / JSP
- **Altro**: integrazione con sistemi IBM Host, Apache POI per i documenti Office

## Frontend

- **Angular** 16–19: componenti standalone, signals, Angular Material, app installabili (PWA)
- **AngularJS**, con ottimizzazione delle prestazioni su grandi volumi di dati
- jQuery, Quill.js; React in passato, su un progetto bancario
- TypeScript, JavaScript, Node.js, HTML5, CSS

## Database

- **SQL Server**, **Oracle** (8–11), **PostgreSQL**, MySQL
- **MongoDB**, VoltDB
- Stored procedure, ottimizzazione delle query, migrazioni di schema con Flyway

## Application server

WebSphere · WildFly · JBoss · Tomcat · GlassFish

## Cloud e DevOps

- **AWS**: Lambda (con SnapStart), API Gateway, Cognito, EventBridge Scheduler, SSM Parameter Store; infrastruttura
  come codice con **AWS CDK** in Java
- **Docker**
- **CI/CD**: Jenkins, GitLab CI
- **Build e versionamento**: Maven, Ant, Git, SVN, IBM RTC

## Test e qualità

JUnit · Mockito · Testcontainers · Cypress (end-to-end e accessibilità) · SonarQube · OWASP Dependency-Check

## Monitoraggio e reporting

| Strumento | Utilizzo |
|---|---|
| Log4j2, Elasticsearch, Kibana (ELK) | Log centralizzati e monitoraggio |
| JasperReports | Report e documenti PDF |
| SSRS | Report enterprise |

## Strumenti

IntelliJ IDEA · NetBeans · JIRA · assistenti AI per lo sviluppo (Claude, ChatGPT, Gemini)

## Metodo di lavoro

- Analisi dei requisiti, reverse engineering di sistemi esistenti, documentazione tecnica e funzionale
- Approccio Agile, gestione degli SLA
- Rapporto diretto con il cliente finale
- Coordinamento di un team di sviluppo (4 persone)
